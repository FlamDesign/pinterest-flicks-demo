# Flicks on Pinterest: concept demo

Clickable concept showing Flicks inside Pinterest, across the categories Pinterest users search most: fashion, food and drink, holiday gifts, home decor, beauty, autos, pets and fitness. Flicks appear as standard Pins, max-width video, Idea ads, a quiz ad, Top of Search, a collection ad, shopping ads, the Pin close-up with "Shop this Pin" synced to the Flick, and a visual search ad. Open "Ad formats" at the bottom right to jump to each placement. Responsive for desktop and phone.
